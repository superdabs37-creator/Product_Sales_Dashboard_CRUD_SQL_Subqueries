Product Sales Dashboard (CRUD + SQL Subqueries)
-------------------------------------------------
This project demonstrates CRUD operations and SQL subqueries using PHP + MySQL.

SETUP INSTRUCTIONS:
1. Import db.sql into your MySQL server.
2. Update config.php with your database credentials.
3. Place all files in your web root folder (e.g., htdocs or www).
4. Open http://localhost/index.php in your browser.

FILES INCLUDED:
- db.sql  (Database schema & sample data)
- config.php  (Database connection)
- header.php, footer.php  (Layout templates)
- index.php  (Product list with subquery total sold)
- create_product.php, edit_product.php, delete_product.php  (CRUD)
- add_order.php  (Add orders)
- analytics.php  (Dynamic analytics using SQL subqueries)
